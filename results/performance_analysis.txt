AI TRAVEL-TIME PREDICTION
PERFORMANCE ANALYSIS
=====================

Model:
Multiple Linear Regression

Input Features:
1. Distance (km)
2. Traffic Level (1-3)

Traffic Levels:
1 = Low
2 = Medium
3 = High

Target:
Travel Time (minutes)

Regression Equation:
Travel Time = -10.30 + 1.80(Distance) + 7.41(Traffic)

Dataset Records:
20

Mean Absolute Error:
4.08 minutes

PERFORMANCE OBSERVATION
-----------------------

The AI model uses route distance and traffic level to
estimate emergency vehicle travel time.

As the distance increases, the predicted travel time
generally increases.

Higher traffic levels also increase the predicted
travel time.

The model achieved a Mean Absolute Error of 4.08 minutes
on the modified project dataset.

The model uses multiple linear regression to provide
an explainable AI extension to the emergency vehicle
route planner.
