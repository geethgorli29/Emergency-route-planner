AI TRAVEL-TIME PREDICTION
PERFORMANCE ANALYSIS
=====================

Model:
Multiple Linear Regression

Input Features:
1. Distance (km)
2. Traffic Level (1-5)

Target:
Travel Time (minutes)

Regression Equation:
Travel Time = -6.99 + 1.74(Distance) + 5.13(Traffic)

Dataset Records:
20

Mean Absolute Error:
2.35 minutes


TEST RESULTS
------------

PERFORMANCE OBSERVATION
-----------------------

The AI model uses route distance and traffic level to
estimate emergency vehicle travel time.

As the distance increases, the predicted travel time
generally increases.

Higher traffic levels also increase the predicted
travel time.

The model achieved a Mean Absolute Error of 2.35 minutes
on the project dataset.

This provides an explainable AI extension to the
emergency vehicle route planner.
